# Task 6 - Create a Strong Password and Evaluate Its Strength

## Objective

To understand the characteristics of a strong password and evaluate its strength using an online password strength checker.

## Tools Used

- PasswordMeter (or any online password strength checker)
- Web Browser

## Procedure

1. Created passwords with different levels of complexity.
2. Tested each password using an online password strength checker.
3. Observed the strength score and feedback.
4. Compared the results.
5. Learned the best practices for creating secure passwords.

## Learning Outcomes

- Understood the importance of strong passwords.
- Learned how password length and complexity improve security.
- Gained knowledge about common password attacks.
- Learned best practices for creating secure passwords.

## Conclusion

Creating strong and unique passwords is essential for protecting online accounts. Using long passwords with a combination of letters, numbers, and special characters greatly improves security and helps prevent unauthorized access.
